# 角色着色器 HGRP/CharacterNPR

角色不是一个 shader，是一族五个：同一套 ForwardLit 骨架，按部位换特性集。
材质 guid **每次 AssetRipper 导出都重生成**，认族只能靠 shader 名或属性签名。

| shader | 用在 | 只有它声明的属性（签名） |
|---|---|---|
| `HGRP/CharacterNPR` | 布料、通用件 | `_AnisotropyDirectionMain` `_SilkStockingsMask` `_FurMap` `_ErosionPatternMap` |
| `HGRP/CharacterNPR_Skin` | **脸和身体都用它** | `_SDFLightmap` `_SDFMask` `_EmotionMap` `_FaceDecalMap` `_SkinRimOffScale` |
| `HGRP/CharacterNPR_Hair` | 头发 | `_SplitNormalMap` `_AnisotropyValue2` `_HairBrowMask` `_SpecBumpScale` |
| `HGRP/CharacterNPR_Eye` | **虹膜和眉毛都用它** | `_EyeTintColor` `_EyeHighLightColor` `_MatcapNormalScale` |
| `HGRP/CharacterNPR_OverlayShadow` | 覆盖在脸上的第二层阴影贴片 | `_ShadowAngleRange` `_ShadowOverIris` |

判据：pelica 实测 —— body/face 同一个 shader guid（`_Skin`），iris/brow 同一个（`_Eye`）。
按「部件名像什么」猜 shader 会错。

`.shader` 文件本身只是变体分发壳：`Properties` 之后整段是
`#if defined(A) && !defined(B) … #include "characternpr/Sub0_Pass0_Fragment_bNNN.hlsl"`，
真正的代码在同名子目录的 2682 个已编译变体里（`Sub0_Pass{0..6}_{Vertex,Fragment}_bNNN.hlsl`，
共 154 MB）。Pass 0 = ForwardLit，1 = CharacterOutline，2 = DepthOnlyOutline，3 = PreGBuffer，
4 = RayTracingReflection，5 = ShadowCaster，6 = TextureStreamingFeedback。
变体文件头两行写着它的 keyword 集合，这是选变体的唯一可靠办法。

## NPR 的核心：影色不是「albedo 乘一个系数」

```
albedo      = _BaseMap.rgb * _BaseColor.rgb                  （脸再叠 emotion 图集）
shadowBase  = albedo * _ShadowColorBrightness
shadowColor = lerp(luma(shadowBase), shadowBase, _ShadowColorSaturation)
```

`_ShadowColorSaturation` 常态 > 1（pelica 脸/身体 1.4，皮肤默认 1.2）——**是外插，不是插值**，
暗部因此比亮部更艳。luma 权重 = Rec.709 `(0.21267290, 0.71515220, 0.07217500)`。

漫反射不是 `NdotL * albedo`，是在两个颜色之间取：

```
kd      = 0.96 - 0.96 * metallic
term    = smoothstep(0.25, 1.0, NdotL)        ← 无 ramp 时
        = _DiffRampMap 采样结果的 ALPHA        ← 有 ramp 时（出货材质全都有）
diffuse = lerp(shadowColor * kd, albedo * kd, term)
diffuse *= lerp(1, ramp.rgb, max3(ramp.rgb) - min3(ramp.rgb))   ← 用 ramp 自身的彩度加权染色
```

`_DiffRampMap` 采样坐标 = `(x * 0.5 + 0.5, 0.5)`，x 在身体上就是 `clamp(NdotL, -1, 1)`。
高光 F0 = `lerp(0.04 * _Specular, albedo, metallic)`，`roughness = 1 - _Smoothness`，
`a = max(roughness², 0.0078125)`，可见度项 `0.5 / (2*NdotV + a + 1e-4)`，结果 `clamp(…, 0, 20)`。

## 通道打包（逐指令确认，非猜测）

| 贴图 | 通道 |
|---|---|
| `_MetallicGlossMap` | R=Metallic（发丝里同时当「用模型切线」混合量） G=Specular Scale B=ShadowMask A=Smoothness |
| `_SplitNormalMap`（仅发） | RG=漫反射法线（×`_BumpScale`） BA=**另一条**高光法线（×`_SpecBumpScale`），只用来位移各向异性高光 |
| `_SDFMask`（脸） | G=SDF 生效区（决定 ramp 坐标走 SDF 还是走 NdotL） B=脸/皮肤 rim 强度选择 |
| `_SDFLightmap`（脸） | R,G=SDF 距离场（取 `(r+g)*0.5`） B=脸朝向编码 |
| `_EmotionMap`（脸） | 2×2 图集，格子 = `(fmod(idx,2)*0.5, floor(idx*0.5)*0.5)`，UV 再 ×0.5；A 为混合权重 |

法线解包 = Unity `UnpackNormalmapRGorAG`：`a *= r; xy = (a,g)*2-1;
z = max(1e-16, sqrt(1 - saturate(dot(xy,xy)))); xy *= _BumpScale`。
**半球先重建、缩放后乘**——顺序反了在 `_BumpScale > 1` 时 z 会塌成 0，两种顺序只在恰好等于 1 时一致。

## `_ShadowLutTex` 是 32³ 色彩查找表，不是渐变条

1024×32 的条带，**用 albedo 自己去查**：

```
srgb = saturate(LinearToSRGB(albedo))        精确分段，指数 1/2.4
b = srgb.b*31 ; b0 = floor(b)
u = srgb.r*31/1024 + 0.5/1024 + b0/32
v = srgb.g*31/32  + 0.5/32
out = lerp(LUT(u,v), LUT(u+1/32, v), b-b0)
```

用它的材质把 `_ShadowColorBrightness/Saturation` 整个换掉：一张表说完整个影色调色板。

## 脸的阴影来自 SDF，不来自法线

```
L_obj    = 光方向变到物体空间，y 清零后归一化
isRight  = L_obj.x > 0
uv.x     = lerp(1 - u, u, isRight)            ← 按受光侧镜像采样
bias     = lerp(L_obj.z, halfLambert(L_obj.z), 背光混合) * 0.5
t        = clamp(0.5 - bias, 0.001, 0.999)
shadow   = smoothstep(max(t-(1-t), 0), min(t+t, 1), (sdf.r+sdf.g)*0.5)
rampX    = lerp(lerp(-1,1, abs(-shadow - bias*ceil(bias))), clamp(NdotL,-1,1), _SDFMask.g)
```

`halfLambert(x) = -x*(x*0.5 - 1) + 0.5`。脸上一整块由 `_SDFMask.g` 决定走哪条。

## 发丝各向异性：两层 Kajiya-Kay + 一条「高光线」

切线不取模型切线，是拿高光法线现算的：

```
T   = cross(specN, lerp(cross(specN, normalize(objToWorld * (_AnisotropyDirX,1,0))),
                        meshTangent, mg.r))
edge = pow(saturate(dot(normalize(specN_obj.xz), normalize(V_obj.xz))), _AnisotropyEdgeFade)
T1  = normalize(T + specN * (_AnisotropyValue*2 - 1))
lobe1 = saturate(pow(max(sqrt(1 - dot(T1,H)²), 1e-4), 200) * mg.g)      ← 指数固定 200
      *= _SpecRampMap(lobe1.x, (dot(T1,H) > 0) * edge²).rgb * edge
lobe2 同式，指数 = floor(200 * max(1 - _AnisotropyRange2, 0))，颜色 _AnisotropyColor2 * mg.a，
      被 lobe1 的 max3 压掉
line  = 第三条同式的窄叶，配 uv.x*_LineAmount 的条纹或 _LineMap.r，压暗漫反射并降饱和
```

## 眼睛

虹膜的 `_BaseMap` 走视差偏移：`uv -= normalize(切线空间视向).xy * _ParallaxScale * (1, 0.25)
* smoothstep(0.25, 0.05, |切线空间视向.xy|²)`。matcap 坐标 = 视空间法线 `.xy*0.5+0.5`。
高光/散射是**乘在影色上的染色**，不是加光：
`shadowColor * lerp(1, _EyeHighLightColor, mask) * lerp(1, _EyeScatteringColor, alpha)`，
其中 `mask = step(0.25, |切线空间视向.xy|²)`。

## 不属于材质的东西

`_CharacterParams0..15` 是**每帧游戏态**（天气、湿身、自定义主光、受击闪白、曝光），
从全局 cbuffer 来，不在 `UnityPerMaterial` 里；中性值下每一项都是恒等。
`_ShadowColorInput` `_Albedo` `_PBRInput` `_Outline` `_NPRInput` `_Anisotropy` 这些
**只是自定义 Inspector 的折叠标记**，压根不进 cbuffer。

## 描边是第二个 Pass，不是材质

`CharacterOutline` 沿平滑法线外扩顶点，宽度在顶点着色器里按裁剪空间位置缩放（所以屏幕上恒定，
没有「多少米」的等价物）。颜色走的是和影色同一条重映射，只是换了自己那对旋钮：
`lerp(luma(albedo*_OutlineColorBrightness), albedo*_OutlineColorBrightness, _OutlineColorSaturation)`，
或被 `_OutlineTintColor` 整个顶掉。
